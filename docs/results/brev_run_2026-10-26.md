## Setup lessons (fixed in `infra/brev_setup.sh` on this branch)
- **Login user:** massedcompute instances log in as `shadeform`, not `ubuntu`: workspace and cache paths now follow `$HOME`.
- **vLLM 0.32 and nvcc:** the image has no `nvcc`.
  - FlashInfer's sampler JIT-compiles, so the engine died after loading: `VLLM_USE_FLASHINFER_SAMPLER=0`.
  - An **FP8 KV cache** makes vLLM pick FlashInfer *attention*, which also needs nvcc. For the 32B run we used
    `VLLM_ATTENTION_BACKEND=FLASH_ATTN` with a bf16 KV cache at `--gpu-memory-utilization 0.88` (6.5 GB of KV, enough
    for 16k-token contexts, fewer parallel requests).
- **Tool calls:** the agent sends tools, and vLLM answers HTTP 400 without `--enable-auto-tool-choice --tool-call-parser
  hermes`.
- **Errors:** the runner's stop-after-20-consecutive-errors caught that 400 within seconds instead of filling a whole run
  with errors.
